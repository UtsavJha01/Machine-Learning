# Pandas-Practice

A collection of **Pandas practice programs, exercises, and examples** created while learning and improving Python data manipulation and analysis skills.

## 📌 About

This repository contains hands-on practice with **Pandas**, one of the most widely used Python libraries for:

- Data manipulation
- Data cleaning
- Data analysis
- Working with CSV and Excel files
- Series and DataFrames
- Filtering and sorting data
- Handling missing values
- Grouping and aggregation

The goal is to build a strong foundation in Pandas through practical coding exercises.

## 🛠️ Technologies Used

- **Python 3**
- **Pandas**
- **VS Code**

## 🚀 Getting Started

### Clone the Repository

```bash
git clone https://github.com/UtsavJha01/Pandas-Practice.git
```

### Navigate to the Repository

```bash
cd Pandas-Practice
```

### Install Pandas

```bash
pip install pandas
```

You can then run the Python programs using **VS Code** or open the notebooks using **Jupyter Notebook**.
